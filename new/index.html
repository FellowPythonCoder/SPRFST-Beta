Lesson 1 of 10 · The beginning

How a program is made

SPRFST is a language of its own: your file is read, understood, checked, turned into instructions and run — by one program, in about the time it takes to let go of the return key.

One binary does all of it. No build file, no toolchain to install.

The smallest whole program

Three things worth noticing: use brings in a part of the library, nothing is in scope by accident. fn main is where every program begins. And a comment is two tildes — this language is not pretending to be C.

hello.spf

io.say took a number without being asked to convert it, and printed a line break for you. Change the 2s and press Run again — if the runner is on, that really compiles.

When it goes wrong. Break something on purpose — type io.sayy — and you get the code, the file, the line, the column, the underline, and the six functions that module actually has. Good errors are not decoration; they are most of what it feels like to use a language.

Lesson 2 of 10 · The basics

Values and names

Two ways to name a thing, five kinds of thing to name, and one rule about division that most languages get wrong.

Int, Num, Text, Bool, Nil — and the compiler works out which, from the value.

You never wrote a type above and yet everything has one. That is inference, not absence: give count a piece of text later and the program will not build.

values.spf

Anything inside braces in a piece of text is filled in — a name, a sum, a whole function call. If you ever need a real brace, double it.

Lesson 4 of 10 · Building blocks

Functions

Named work with its shape written on the outside — and functions are values, so one can be handed to another.

Left to right, in the order it happens — that is what |> is for.
functions.spf

give hands the answer back. A function that is one expression drops the braces and uses =>. apply_twice takes another function as an ordinary argument, and add is a function with no name at all.

Lesson 6 of 10 · The important one

Nothing, and failure

Missing and failed are different ideas, so they get different tools — and neither of them can be ignored by accident.

A missing value cannot slip past and turn into a crash an hour later.
nothing.spf

match is not only for Results. Make your own kinds with enum — each one can carry values — and the compiler will tell you when you have forgotten a case.

Write initial: it takes a name that might not be there and gives back the first letter in capitals, or a question mark.

Lesson 7 of 10 · Structure

Shapes of your own

A thing with an identity, a value that is only its contents, and a promise that any of them can keep. No inheritance anywhere.

No base class, no super, no diamond. A small promise kept is worth more than a family tree.
shapes.spf

Fields carry their defaults, so building one means naming only what is different. Methods take self first. A trait can carry a finished method written in terms of the ones it demands — greet was written once and both shapes got it.

Your turn

Write last_of — the other end of first_of, for any type at all.

3 b true
The last position is items.len() - 1. Give nil when the list is empty, so the answer has to be T?.
use std.io fn last_of(items: [T]) -> T? { if items.is_empty() { give nil } give items[items.len() - 1] } fn main() { io.say("{last_of([1, 2, 3]) ?? 0}") io.say(last_of(["a", "b"]) ?? "-") io.say("{last_of([]) == nil}") }
Lesson 9 of 10 · Underneath

Memory, and doing several things

Who owns this, who is only borrowing it, what happens when the function leaves — and how to do two things at once.

Also real threads, channels, locks and atomics in std.thread.
memory.spf

add_one changed the caller's list, because it was handed the same list — not a copy. finished printed last even though it was written first: that is defer, and it is how you close a file next to where you opened it and stop thinking about it.

Said plainly. Tasks run on real threads, but the interpreter holds one lock, so this is concurrency for overlapping waiting — not yet for using eight cores at once. It is written down in the project's README under Status, and a native backend is the next big piece of work.
100 points

Your turn

Use all three: a defer that prints done last, a clone that does not change when the original does, and a spawned task that triples seven.

[1, 2] [1] 21 done
Clone before you push. You can write await spawn triple(7) in one breath.
use std.io task triple(n: Int) -> Int { give n * 3 } fn main() { defer io.say("done") var first = [1] let second = clone(first) first.push(2) io.say("{first} {second}") io.say("{await spawn triple(7)}") }

Your turn — the last one

Count the words in "a storm is a storm is a wind". Print how many different ones there are, then the commonest and how often it appears.

4 different words a appears 3 times
Walk counts.keys() keeping the biggest you have seen. counts.len() is how many different words there were.
use std.io fn main() { let text = "a storm is a storm is a wind" var counts: Map = [:] for word in text.split(" ") { counts.set(word, (counts.get(word) ?? 0) + 1) } var best = "" var most = 0 for key in counts.keys() { let n = counts.get(key) ?? 0 if n > most { most = n best = key } } io.say("{counts.len()} different words") io.say("{best} appears {most} times") }

What it cannot do yet. sprfst build writes optimised instructions rather than a standalone binary; a native ARM backend is the next major piece of work.
